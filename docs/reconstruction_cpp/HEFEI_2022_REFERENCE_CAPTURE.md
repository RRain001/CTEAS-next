## Known deviations from the locked specification

- Grid origin precision: the locked absolute geometry is XORIGKM=510.8846439571007 km, YORIGKM=3531.2689269678035 km (crop centre minus half domain). The canonical control renderers write 3 decimals, so every deck used XORIGKM=510.885 km, YORIGKM=3531.269 km; the SW corner therefore differs by 0.3560 m in x and 0.0730 m in y from the exact spec. Terrain, landuse, CALMET and CALPUFF all read this same rounded origin, so the captured chain is internally consistent; the residual offset is documented, not resolved.
- Point-source coordinates are written to 3 decimals by the CALPUFF renderer: deck (513.385, 3533.769) km versus the exact crop centre (513.3846439571007, 3533.7689269678035) km, i.e. 0.3560 m / 0.0730 m.
- Annual HTO release 2.63e+13 Bq/year is injected with CALPUFF IPTU=8 (Bq/s) at 833967.5291730086 Bq/s, assuming 3.1536e+07 s/year. The locked document leaves the 'release window/hourly rate' as TBD, so the year length is an explicit choice, not a verified legacy control.
- Stack base elevation is 0.0 m (ground datum) because the locked document lists 'datum and original height representation' as TBD. The terrain elevation at the stack cell is available in geo/makegeo/geo.dat for a later datum decision.
- NM3D=0 with IUPWND=-1: with no MM4/MM5/3D.DAT input and NOOBS=0 the initial guess field is built from the single upper-air sounding; this combination was not independently verified against the vendor documentation, only exercised end to end.
- IKINE=0 / IFRADJ=1 / ISLOPE=1 / IEXTRP=-4 are the values of the real user deck and of engine/templates/met.inp; the locked document records them as deck values, not as values derived from a primary CTEAS specification.
