## 3. 隔离与跨年风险

1. **导入时全局绑定**：download_igra.py:13、parse_igra_to_csv.py:13、read.py:7 的 DATA_ROOT 与 merge_final_upperair.py:12-16 的 CASE_ROOT/UPPERAIR_ROOT/RESEARCH_TIME_FILE/FINAL_STATIONS_CSV 均在导入时取 current case。runner 24-31、105 行再次隐式取 current。仅传 subprocess cwd 无法隔离；不应通过修改 current_case 或 symlink 实现新案例。
2. **离线入口不足**：download_igra.py:78-119 有已有非空文件复用，否则自动联网；prepare_inputs 有 skip-download，runner 只有 skip-inputs。新入口须明确离线归档映射与禁止联网模式，并保留年度资格筛选，不能将“跳过下载”解释为“跳过 QA”。
3. **跨年 union 并非静态站网已验收**：merger 188-225 按五位 WMO union 收集现存文件，缺目录时 continue，坐标/名称/高程用 setdefault 保留首年；同一 WMO 跨年源身份/有效位置变化以及只在某年出现的站未做完整连续性检查。runner 105-108 仅验证文件存在；元数据缺失检查在写出后才发生（merger 291-300）。不能把 union 文件头声明的完整研究时段视为全时段真实可用性。
4. **旧文件污染**：merger 196-201 glob 所有 up_*.dat；不是仅消费本次作业清单。应使用独立新 run 目录与显式产物列表，拒绝本次未选站的遗留文件，不删除用户已有目录。
5. **真实前后探空合同缺口**：runner 37-39 将年度 writer 窗口裁至研究 begin/end，writer 101 行丢弃窗口外探空。非 00/12 起止及跨年边缘可能缺 AA/BB。merger 158-185、268 无条件把最后一条 +12h 克隆，不能冒充真实后括号。既有缺测处理不在本任务改写；应在来源 metadata 区分原始/克隆，并在 G19 声明真实边界之前验证真实来源。
6. **SHA 不足**：runner manifest 109-112 记录作业、命令、路径和 binary 路径，没有源站表/原始 NOAA/FSL/annual UP/final UP/binary SHA；selection audit 179-191、252-259 有来源坐标/覆盖但无完整字节身份链。
7. **三位 UTM 原点门禁**：station_grid.py:14-22 校验 UTM/有限值/正尺寸，但 common.py:95-96 直接 float 解析 XREF/YREF，没有检查原始字符串恰为三位小数。已合并 B-0 要求统一验证，P4 实现应消费该验证结果；不可使用高精度重新投影的中心原点替代 grid.cmn。FSL 地理经纬度六位规则与 UTM km 三位规则属于不同字段。

`scripts/s2g/real_noaa_native_p4_up.py:44-48,70-75` 固定 Anqing/2022/2023/6h；112-123 通过进程内 patch 隔离生产者全局变量。该脚本可作为回归样例，不应成为通用入口或复制 monkeypatch 方案。它 158-175 行只复用 normalize、不调用末条克隆，使用显式扩展真实探空窗口并执行原生 G19 源预检；184-199 行检查错误 WMO 和缺失未来括号均拒绝。旧 merger 发布路径必须满足已合并 B-0 的真实 00/12 探空括号要求；具体窗口适配及来源门禁仍待模块审查。
