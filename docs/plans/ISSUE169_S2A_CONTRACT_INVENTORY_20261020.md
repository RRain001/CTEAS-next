## Minimum common manifest and blocking semantics

The orchestration adapter needs **no new physical kernel**: input case/grid/time SHA256 (and `case_name`), producer exact executable Git SHA and method ID, all original source file SHA256 (TIFF/GLCC/NOAA/Full BLN), source product/year, actual zone/hemisphere, literal X/Y, NX/NY/DGRIDKM, P2 category order 38, output path/SHA/row order/format, only applicable station IDs/effective coordinates and UTC coverage, real-vs-synthetic evidence kind, independent original comparison run/artifact and scoped result. Producer output is `PRODUCED_UNVERIFIED` until independent reference completes; do not infer original parity from self-generated metadata.

Before producer invocation: reject missing/changed case SHA, wrong grid/header, unsupported CRS/source raster/resolution/clock/station count, stale or symlinked output path, root inside repo/frozen data, duplicate config keys or incompatible option profile. After: verify immutable case; inspect rows and original product SHA. S2's software positive does not automatically imply scientific acceptance.
